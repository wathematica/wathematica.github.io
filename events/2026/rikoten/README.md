# 理工展2026 特設ページ

公開ページ: `https://wathematica.github.io/events/2026/rikoten/rikoten.html`
ディレクトリURL `/events/2026/rikoten/` からも移動できます。
HTML / CSS / JavaScriptを使用し、GitHub Pagesでそのまま公開できます。ビルドは不要です。

## 公開前・公開当日の切り替え

現在は非公開モードです。タイトル・概要・科目・星だけを掲載し、ポスター画像・PDFプレビュー・ダウンロードを表示しません。科目・星の絞り込みと星の少ない順の並びは利用できます。

リポジトリルートで次のコマンドを実行し、通常どおりコミット・デプロイすると切り替わります。日付による自動公開は行いません。

```sh
# 当日：素材の配置と公開表示をまとめて切り替える
python3 events/2026/rikoten/manage_publication.py publish

# 非公開へ戻す
python3 events/2026/rikoten/manage_publication.py unpublish

# 現在の状態を確認
python3 events/2026/rikoten/manage_publication.py status
```

表示状態は `data.js` の `publication.postersPublic` で管理します。手でフラグだけを変えると素材の配置と一致しないため、上記コマンドを使ってください。

非公開の原本は `_private/poster/`、プレビュー画像は `_private/assets/posters/`、以前のサンプルPDFは `_private/assets/pdfs/` に保管しています。`_private/` はこのディレクトリの `.gitignore` でGitから除外し、先頭が `_` のディレクトリなのでGitHub PagesのJekyll公開対象にも含まれません。公開時は原本を保管したまま公開先にコピーし、非公開へ戻すと公開先から保管場所に移します。活動写真 (`poster/pictures/`) は常に公開用として残ります。非公開素材はGitには入らないため、別のPCに移る場合は保管フォルダも引き継いでください。

新しいポスター素材は、非公開中は `_private/` の対応するディレクトリに追加し、`data.js` のパスには公開時の `./poster/...`、`./assets/posters/...` を指定します。元PDFが既に過去のコミットや公開サイトに含まれている場合、この切り替えだけで過去の履歴や既存の公開物を消すことはできません。

現在はユーザー提供の日程「2026年11月7日・8日」、教室「61号館201」を登録しています。開催時間の表示は設けていません。地図はユーザー指定の共有リンクの行き先（61号館）を示し、教室内の位置を示すものではありません。地図はGoogle Mapsから読み込みます。

- 連番の深層学習入門・高次対称性・アノマリー・BH情報喪失問題・岩澤類数公式・バイバインは、展示ごとにまとめています。

- 第五公準の2ファイルも描画が同じため、著者名を含むファイルを掲載しています。
- Riemann面の2ページはひとつの展示として掲載しています。
- `sourcePdfs` に各展示の元ファイル（重複を含む）を記録しています。元PDFは変更していません。

ポスター追加時は `posters` 配列に次の形式のオブジェクトを追加します。idは一意にしてください。

```javascript
{
  id: "new-poster",
  title: "ポスタータイトル",
  category: "数学",
  stars: 1,
  description: "100〜200文字程度の概要",
  image: "./assets/posters/new-poster.webp",
  pdf: "./poster/new-poster.pdf",
  sample: false
}
```

公開時はPDFを `poster/`、プレビュー画像を `assets/posters/` に配置します。非公開中の保管場所は上記の `_private/` です。パスはrikoten.html基準の相対パスです。既存の `assets/pdfs/` も使用できます。画像は縦横比を維持し、遅延読み込みします。

## 複数枚のポスター

ひとつの展示はひとつのオブジェクトにまとめ、`parts` に表示順で画像・PDFを指定します。カード下部とページ内プレビューのボタンで切り替えられます。フィルターの件数は展示単位です。

```javascript
{
  id: "series-001",
  title: "複数枚のポスター",
  category: "数学",
  stars: 1,
  description: "展示全体の概要",
  sample: false,
  parts: [
    { label: "1枚目", image: "./assets/posters/series-1.webp", pdf: "./poster/series-1.pdf" },
    { label: "2枚目", image: "./assets/posters/series-2.webp", pdf: "./poster/series-2.pdf" }
  ]
}
```

1つのPDF内に複数ページがある場合、`pdf: "./poster/series.pdf#page=2"` のように指定するとページ内プレビューが指定ページにスクロールします。`parts` のない従来のデータも使えます。

## ページ内PDFプレビュー

カードをクリック（またはEnter / Space）すると、同じページのダイアログ内でPDFが表示されます。Escape・閉じるボタン・背景クリックで閉じ、元のカードにフォーカスが戻ります。

カード下部とプレビュー内の「ダウンロード」で選択中の元PDF全体を保存します。PDF内のページ指定がある場合も、その1ページだけではなく元ファイル全体が対象です。

PDF表示には同梱のMozilla PDF.js 6.4.299（互換性を補うlegacyビルド、Apache-2.0）を使用します。`vendor/pdfjs/` にライブラリ・Worker・フォント等・LICENSEを配置し、プレビューを開いた時に読み込みます。CDN接続・ビルド作業は不要です。読み込み失敗時はダウンロードを利用できます。プレビューはCanvas描画のため、スクリーンリーダーやテキスト選択には元PDFをダウンロードして閲覧してください。

## 星の数・絞り込み・並べ替え

各ポスターの `stars` に、PDFヘッダーに表示された黄色い星の数（1・2・3）を登録しています。連続するポスターは表紙の星を展示全体の目安として使用します。星1つは高校生、2つは学部1・2年生、3つは学部3年生以上向けです。

分野と星のフィルターは組み合わせて使えます。並び順は星の少ない順（★ → ★★ → ★★★）に固定しています。同じ星の数では元の掲載順を維持し、未設定の場合は末尾に置きます。現時点では星1つが6展示、2つが8展示、3つが13展示です。

## 冒頭の写真スライドショー

`data.js` の `slides` 配列で、写真の表示順・パス (`src`)・説明 (`alt`)・元画像の幅と高さ (`width`, `height`) を管理します。縦長の写真は `fit: "contain"` で全体を表示し、横長の写真は `position` で切り取り位置を指定できます。

`poster/pictures/` の去年の展示写真3枚を5秒ごとに横へスライドして切り替えます。操作ボタンや写真選択ボタンは設けず、自動で切り替わります。画面外・別タブでは自動切り替えを止めます。動きを減らす設定では自動再生を停止します。追加ライブラリは使用していません。

追加分として「線型代数から理解する岩澤類数公式」（4枚）、「バイバインをかけた饅頭は何時間後にブラックホールになるか」（2枚）、「おりがみ」「ブール値モデル」「Transformerの基本的なスケーリング則」を登録しました。バイバインは1枚目が星1つ、2枚目が星2つです。展示全体の絞り込みは従来どおり1枚目の星を使用し、各枚の星も `parts[].stars` に記録しています。

「複素領域における線形微分方程式」（数学・星3つ・全3枚）を追加しています。
